Knot Forum API

A small, authenticated text-forum backend for posts, comments, and likes.

What This API Supports

  • User authentication with password login.
  • Create and view forum posts and comments.
  • Like posts (one like per user, and users cannot like their own posts).
  • Moderator flagging for misleading or false information.
  • AI-enhanced forum capability (based on the selected extension option).

Quick Start

Use the API from your frontend or tools like Postman. Anonymous users can view public content, while posting, commenting, and liking require authentication.

Example Endpoint

GET /api/hello/ returns a basic API health message.
