Knot

REST API — Django backend • Session-based auth • AI post categorisation

Authentication: All endpoints use session cookies. Call POST /api/auth/login/ first, then include credentials: "include" (or equivalent) on every subsequent request. The session cookie is set automatically by Django.

Authentication

Method Endpoint Auth Description
POST /api/auth/register/ — Create a new user account
POST /api/auth/login/ — Log in and establish a session
POST /api/auth/logout/ — Destroy the current session
GET /api/auth/me/ — Return the authenticated user or null

Posts

Method Endpoint Auth Description
GET /api/posts/ — List all posts — pass ?user_id=<id> to include like state
POST /api/posts/create/ Required Create a post — AI categorisation is triggered automatically
POST /api/posts/<id>/comments/ Required Add a comment to a post
POST /api/posts/<id>/like/ Required Toggle a like on a post (cannot like own posts)
POST /api/posts/<id>/misleading/ Moderator Mark or unmark a post as misleading

Utility

Method Endpoint Auth Description
GET /api/stats/ — Forum-wide counts: users, posts, likes, comments
GET /api/users/ — List all users ordered by username
POST /api/users/create/ — Create or retrieve a user by username
